# Signer & Broker Environment

Authoritative inventory of every environment variable the signer and broker
read at runtime. Generated by grepping `signer/` and `broker/src/` for
`os.environ` / `process.env` / `env.` accesses.

Do NOT commit any value. All secrets are provisioned via Railway service
config; only the variable *names* live in the repo.

## Signer (private Railway service — not publicly routable)

| Variable | Purpose | Source |
|---|---|---|
| `SIGNER_SHARED_SECRET` | HMAC key for every inbound request from the broker. Rotate on any suspected compromise. | Owner-generated random (32+ bytes, base64 or hex). Same value provisioned on broker. |
| `SIGNER_ALLOWED_SKEW_SECONDS` | Replay window for HMAC-signed requests. Default `30`. | Owner. Numeric string. |
| `APEX_MASTER_WRAPPING_KEY_V1` | Master AES-256-GCM wrapping key (v1). Wraps every per-bundle DEK. | Owner-generated (32 random bytes, base64). Never rotated in place; new versions get `_V2`, `_V3`, … |
| `APEX_MASTER_WRAPPING_KEY_ACTIVE` | Integer version selector (e.g. `1`) — which `_V{n}` key `encrypt_bundle` uses. | Owner. Numeric string. |
| `APEX_MAINNET_SIGNER_ENABLED` | Master gate for `/v1/onboard` and every write op. Default off. | Owner flag. `true` / `false`. |
| `APEX_MAINNET_CANARY_ENABLED` | Gate for order-emitting ops (CREATE_ORDER / CLOSE_*). Default off. | Owner flag. `true` / `false`. |
| `APEX_OMNI_BASE_URL_MAINNET` | ApeX Omni mainnet REST base URL. | Owner. Static. |
| `APEX_OMNI_BASE_URL_TESTNET` | ApeX Omni testnet REST base URL. | Owner. Static. |
| `SUPABASE_URL` | Backend URL for persisting `apex_execution_credentials`, audit rows, and reading `exchange_connections`. | Backend project (managed). |
| `SUPABASE_PUBLISHABLE_KEY` | Publishable (or legacy anon) key. `/v1/onboard` builds a per-request Supabase client bound to the CALLER's Supabase JWT (forwarded by the broker inside the HMAC-covered body); RLS on `apex_execution_credentials` and `apex_credential_audit` restricts every write to `auth.uid() = user_id`. `SUPABASE_ANON_KEY` is accepted as a fallback under the same slot. | Backend project (managed). |
| `SUPABASE_SERVICE_ROLE_KEY` | OPTIONAL. Only required if you later enable one of the `APEX_MAINNET_*` execution flags (order intents / execution paths). Onboarding does NOT need it. | Backend project (managed). Do not paste in chat. |
| `TURTLE_CREDENTIAL_ENCRYPTION_KEY` | Legacy encryption key retained for backward-compatible read paths of pre-envelope credentials. | Owner-generated random. |
| `WORKER_INGEST_SHARED_SECRET` | HMAC key for the worker → `worker-ingest` edge function callback. | Owner-generated random. Same value provisioned on the Python worker. |
| `WORKER_INGEST_KEY_VERSION` | Integer version for the ingest HMAC key. | Owner. Numeric string. |
| `WORKER_INGEST_WORKER_ID` | Identifier for this signer's worker peer (audit label). | Owner. Static string. |

## Broker (public Railway service — JWT-authenticated)

| Variable | Purpose | Source |
|---|---|---|
| `PORT` | HTTP listen port. Railway supplies. | Railway. |
| `NODE_ENV` | `production` / `development`. Controls log verbosity. | Railway. |
| `CORS_ALLOWED_ORIGINS` | Comma-separated allow-list for browser origins. | Owner. Static. |
| `RATE_LIMIT_PER_MIN` | Per-caller request cap. | Owner. Numeric string. |
| `SUPABASE_URL` | Reused for ownership checks against `exchange_connections`. | Backend project (managed). |
| `SUPABASE_PUBLISHABLE_KEY` | Publishable (or legacy anon) key. The broker builds a per-request Supabase client bound to the CALLER's bearer JWT; RLS on `exchange_connections`, `profiles`, and the `is_execution_halted` RPC restricts every read to `auth.uid()`. The broker holds NO service-role key. `SUPABASE_ANON_KEY` is accepted as a fallback under the same slot. | Backend project (managed). |
| `SUPABASE_JWKS_URL` | JWKS endpoint used to verify caller Bearer JWTs. | Backend project (managed). |
| `SUPABASE_JWT_ISSUER` | Expected `iss` claim on caller JWTs. | Backend project (managed). |
| `SIGNER_BASE_URL` | Private URL of the signer service (Railway private networking). | Owner. |
| `SIGNER_SHARED_SECRET` | HMAC key — MUST equal the signer's value. | Owner. |
| `SIGNER_TIMEOUT_MS` | Upstream call timeout to the signer. | Owner. Numeric string. |
| `APEX_MAINNET_SIGNER_ENABLED` | Preflight gate for onboarding / write ops. Broker also checks; signer re-checks. | Owner flag. |
| `APEX_MAINNET_CANARY_ENABLED` | Preflight gate for order-emitting ops. | Owner flag. |
| `APEX_MAINNET_AUTOMATION_ENABLED` | Umbrella automation flag. | Owner flag. |
| `APEX_MAINNET_READS_ENABLED` | Broker-only preflight gate for `READ_*` / `VERIFY_CREDENTIALS`. **Not read anywhere in the signer** (reads are always-enabled by design via `signer/app/operations.py::OPERATION_ENABLED`). Provision once at broker deploy time; not part of the LIVE_ACTIVATION flip sequence. | Owner flag. |

## App server (TanStack Start) — required for the owner console

| Variable | Purpose | Source |
|---|---|---|
| `TURTLE_BROKER_BASE_URL` | Base URL the `signerOnboard` server function calls (`{url}/v1/onboard`). Read only inside the server-function handler. | Owner. Same public broker URL used elsewhere. |

## Provisioning checklist

1. Signer service — every row in the signer table above.
2. Broker service — every row in the broker table above (`SIGNER_SHARED_SECRET`
   must equal signer's).
3. App server — `TURTLE_BROKER_BASE_URL` set in Project Settings → Secrets.
4. All flags default to `false`. Onboarding requires
   `APEX_MAINNET_SIGNER_ENABLED=true` on both broker and signer. Order emission
   additionally requires `APEX_MAINNET_CANARY_ENABLED=true`.
